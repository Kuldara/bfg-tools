BOARDING ACTIONS — WEB-HOSTAUS

Lataa tämän kansion sisältö sellaisenaan minkä tahansa staattisen web-hotellin
julkiseen juurikansioon. Aloitussivu on index.html.

Palvelinpuolta, tietokantaa, npm-asennusta tai ulkoisia kirjastoja ei tarvita.
Sovellus tallentaa keskeneräisen pelin käyttäjän oman selaimen localStorageen.
Käytä julkisessa hostauksessa HTTPS-yhteyttä.

index.html generoidaan projektin juuressa komennolla:

    python build.py

Älä muokkaa index.html-tiedostoa käsin; tee muutokset src-kansioon ja rakenna
paketti uudelleen.
