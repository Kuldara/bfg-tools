# History

Working notes from before October 2026, when each tool lived in its own folder
and the project's working language was Finnish. They are kept as they were, not
translated: they record why things are the way they are (the Registry's backlog
J1-J239, spot checks, task files, external reviews, old builds of 1.0 and 1.1,
each app's development notes).

The living documents in English replace them: the top-level README, ARCHITECTURE
and AGENTS, `packages/rules/CONTRACT.md`, `apps/registry/docs/`,
`reference/README.md` and each app's README, RULINGS and CHANGELOG.
