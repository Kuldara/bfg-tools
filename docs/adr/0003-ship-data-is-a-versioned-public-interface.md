# ADR 0003: The ship data is a versioned public interface

Status: accepted, 2026-10-26

## Context

`bfg_data.json` is extracted from the Fleets Book and the Rulebook. Four
programs read it: the Registry, Play, Boarding and a private simulator. At least
one outside service (Ship Profiles, ships.battlefleet-game.org) reads it daily
from the Registry's published page. Its fields were documented only by the
extractor's code, and a consumer read it from an absolute path on one machine.

## Decision

- The data lives in `data/bfg_data.json`, generated by `extractor/` and committed,
  so every change shows up as a readable diff.
- It carries `schemaVersion`. `data/schema.json` (JSON Schema) describes it and the
  tests validate the data against it.
- `data/README.md` states which fields are stable. Removing or renaming a
  stable field bumps the major schema version and is noted in the changelog.
- The Registry's published site also serves the file at `/bfg_data.json`, which is
  the recommended way for others to read it. The embedded
  `<script id="bfgdata">` stays for offline use and for existing readers.
- Apps read the data from `data/` by relative path, never from outside the repo.
