BFG Tools

Free fan-made tools for Battlefleet Gothic. This is the GitHub Pages mirror; the main addresses are on kuldare.com, and both serve the same files.

  • Gothic Fleet RegistryFleet builder with legality checks and printable ship cards
  • Boarding ActionsResolves a boarding action by the book, one tap at a time
  • Battlezone GeneratorRolls the celestial phenomena and plots the table
  • Scenario LibraryRulebook and Warp Rift scenarios, set up and tracked at the table
  • Meta AlmanacWhat gets played and what wins, every record with its source
Source code, licence and main addresses: github.com/Kuldara/bfg-tools. Unofficial fan project, not endorsed by Games Workshop.
