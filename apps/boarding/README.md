# Boarding Actions

Resolves a Battlefleet Gothic boarding action from start to finish: eligibility,
boarding values, modifiers, dice, the result, critical hits and their tables,
how damage is shared, hulks and catastrophic damage. One HTML file: open it on a
phone, a tablet or a computer. No server, no network, no install. The state stays
in the browser, so a battle left half-way is there when you come back.
Live at [bfgtools.boarding.kuldare.com](https://bfgtools.boarding.kuldare.com/).

## Design: every input is a chance to get it wrong

| What | Comes from |
|---|---|
| hull type, damage points, turrets / spore cysts | the ship's profile |
| crippled, and halved turrets when crippled | computed from the damage left |
| race modifier (+1 Chaos, +2 Space Marines, ...) | the fleet |
| which hulls a fleet may field | the book's fleet lists |
| ratio modifier (+1 to +4) | computed from the boarding values |
| class rules (Endeavour, Hemlock, Blackship, Slaverer, ...) | the profile's special rules |
| the right critical table (Eldar, Tyranid, defences, Ork hulk, ...) | the ship |
| Marks, crews, characters (Khorne, CSM crew, Warlord, Inquisitor, ...) | **asked once per ship**, remembered |
| blast markers and special orders | **two taps per round** |
| dice | the app rolls, or you tap in your own roll |

Once the ships are chosen and their damage is up to date, a boarding action is
**one tap**.

**A fleet is chosen by its crew.** The list of ships is not the book's page order
but what each fleet list fields: the Mechanicus also has its Explorator list's
Imperial hulls, Chaos its renegade hulls, the Space Marines their rapid strike
vessels. The choice decides the modifiers (a Mechanicus Lunar re-rolls, FL p. 118;
a renegade Lunar gets +1 Chaos, FL p. 222). Allies are chosen under their own
fleet, because they keep their own crew.

## Rulings

Where the books contradict each other or are silent, the app decides, and the
decisions are listed in [RULINGS.md](RULINGS.md) so each can be disputed.

## Code

```
index.html          the page; styles/app.css
src/app.js          the interface (one ES module)
src/engine.js       the rules engine: pure functions, no DOM, randomness only
                    through an injected generator (UMD: runs in the page and in Node)
src/ships.json      generated by build_ships.py from data/bfg_data.json (235 hulls)
src/icons.json      generated by make_icons.py
build.js            npm run build -> dist/boarding/index.html, dist/share/Boarding.zip
build_ships.py      picks the hulls, their boarding flags and which fleet crews them
make_icons.py       fleet colours and icons, hull silhouettes
test_engine.js      the books' own examples and sentences as assertions (240)
test_fuzz.js        40 000 random boarding actions through the engine's invariants
```

After a data change: `python apps/boarding/build_ships.py`, then `npm run build`.

- The build refuses to run when a fleet or a hull type has no icon, a colour is
  not `#rrggbb`, or an icon is anything but path/circle geometry. A new fleet in
  `build_ships.py` needs a row in `make_icons.py`'s `FLEETS`, a new hull type a row
  in `H`.
- `build_ships.py` also reads which fleet crews which section of each list
  (`LIST_CREW`, with pages); a new section with a foreign hull and no row stops it.
- Every hand-picked ship rule carries its source sentence, which `build_ships.py`
  looks for in the ship's own rule text: if the data changes so the sentence
  disappears, it stops instead of losing the flag silently.
- Where a book example is itself wrong, its test encodes the undisputed numbers and
  names the dispute in a comment.

## Known limits

- **The Ramilies and the fortress-monastery** have four quadrants; the boarding
  value is all quadrants' remaining hits plus **the boarded quadrant's** turrets
  (FL p. 502). The app handles one quadrant at a time; the others' hits are entered
  by hand (ruling 20). In practice only a space hulk can board them.
- **The Tyranids' All Is Lost** is shown as a timely reminder, but the Leadership
  test is not rolled, since the app does not track Leadership.
- **The Mark of Khorne's +1 to cause criticals** is given to the whole side; in a
  multi-boarding where only some ships have it, this is slightly generous.
- **Hit-and-run attacks and teleports** (same step of the End Phase) are not here:
  they are simple (D6, 1 fails, 2+ roll on the critical table); the critical tables
  are already in the engine if they are wanted.
